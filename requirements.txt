# NOTE: Warehouse drivers (snowflake-connector-python, pymssql, oracledb,
# clickhouse-driver, databricks-sql-connector) live in
# `requirements-warehouse.txt` and are NOT installed by the default
# Dockerfile. Including them here from PR #302 broke `pip install` on
# python:3.11-slim for 7 consecutive staging deploys (CI logs:
# `did not complete successfully: exit code: 2`), which left the demo
# whitelist + signup endpoint undeployed.

# The connector modules already import these lazily and the
# `is_real` flag honestly reports False when the driver is missing,
# so the app boots fine without them. Re-enable them per-environment

# image has the right system headers (or once we move to a beefier
# base image).
